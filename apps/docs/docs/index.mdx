## Install

```bash
curl -fsSL https://raw.githubusercontent.com/urdadx/buncrawl/main/install.sh | sh
```

## Scrape a page

```bash
buncrawl example.com
```

## Run the API server

```bash
docker run -p 3000:3000 ghcr.io/urdadx/buncrawl:latest
```
