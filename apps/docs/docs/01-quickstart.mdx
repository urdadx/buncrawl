## Let your agent do it

The quickest way to start is to hand the setup to your coding agent. Copy this prompt into Claude
Code, Cursor, Codex or whichever agent you use, or click your agent below to copy a prompt made for it:

<Prompt description="Ask your agent to **install Buncrawl** and scrape a first page." actions={["copy"]}>
  Install Buncrawl, the self-hosted web scraper, by following
  https://github.com/urdadx/buncrawl#readme. Run its install script, check `buncrawl --version`,
  then scrape https://example.com with `buncrawl example.com` and show me the Markdown it prints.
  If I want the API server, start it with `buncrawl serve` and set `BUNCRAWL_API_KEY` first.
</Prompt>

<AgentPrompts />

Your agent installs the binary, runs a first scrape, and can start the API server for you.

## Or do it yourself

Prefer to run the commands yourself? Install the binary, scrape a page, crawl a site, then run the
API server.

<Steps>
  <Step title="Install Buncrawl">
    On Linux or macOS (x64 or arm64), the install script downloads the latest release, checks it
    against the release's `SHA256SUMS`, and installs it without `sudo`:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/urdadx/buncrawl/main/install.sh | sh
    ```

    Check it worked with `buncrawl --version`.
  </Step>
  <Step title="Scrape a page">
    Buncrawl prints the page's main content as Markdown:

    ```bash
    buncrawl example.com
    ```

    Pages that need JavaScript are rendered automatically when Chrome or Lightpanda is installed;
    see [Browsers](/self-hosting/browsers).
  </Step>
  <Step title="Crawl a site">
    Follow links from a start page and write each page as a Markdown file:

    ```bash
    buncrawl crawl example.com --limit 20 --out pages
    ```
  </Step>
  <Step title="Start the API server">
    The same binary is the API server. Set a key, then start it on port 3000; it keeps its data in a
    `data` folder:

    ```bash
    BUNCRAWL_API_KEY=change-me-to-16-plus-chars buncrawl serve
    ```

    Prefer Docker, with Chrome and Lightpanda included? See [Docker](/self-hosting/docker).
  </Step>
  <Step title="Call the API">
    Scrape over HTTP with your key:

    ```bash
    curl -s localhost:3000/v1/scrape \
      -H "Authorization: Bearer change-me-to-16-plus-chars" \
      -H "content-type: application/json" \
      -d '{"url": "https://example.com", "formats": ["markdown"]}'
    ```
  </Step>
</Steps>
